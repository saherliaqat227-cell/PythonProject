# 🐦 Twitter Sentiment Analyzer

A Natural Language Processing project for analyzing and classifying Twitter text using Machine Learning and Deep Learning models.

## 📌 Project Overview

This project uses different approaches for Twitter sentiment classification, including:

- Support Vector Machine (SVM)
- Simple RNN
- LSTM
- GRU

The project demonstrates how Machine Learning and Deep Learning techniques can be applied to text classification.

## 🤖 Models

| Model | Type |
|---|---|
| SVM | Machine Learning |
| Simple RNN | Deep Learning |
| LSTM | Deep Learning |
| GRU | Deep Learning |

## 📊 Sentiment Categories

The project works with four sentiment categories:

- Positive
- Negative
- Neutral
- Irrelevant

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- Scikit-learn
- Pandas
- NumPy
- Natural Language Processing (NLP)

## 📂 Project Files

- `main.py` — Main Python application
- `sentiment_svm_pipeline.pkl` — Trained SVM pipeline
- `sentiment_rnn_model.keras` — RNN model
- `LSTM_model.keras` — LSTM model
- `GRU_model.keras` — GRU model
- `label_encoder.pkl` — Sentiment label encoder
- `svm_accuracy.pkl` — Saved SVM accuracy
- `twitter_training.csv` — Training dataset
- `requirements.txt` — Required Python packages

## 🔄 Project Workflow

1. Load the Twitter sentiment dataset.
2. Preprocess the text data.
3. Train Machine Learning and Deep Learning models.
4. Evaluate the models.
5. Compare model performance.
6. Predict sentiment for new text.

## 🎯 Objective

The objective of this project is to explore different Machine Learning and Deep Learning approaches for Twitter sentiment analysis and text classification.
